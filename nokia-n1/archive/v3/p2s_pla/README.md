# P2S PLA 面板切片

使用 Bambu Studio 02.08.02.61 的 P2S 官方预设完成本地切片。没有发送到 3D 打印机。

打开 `n1_front_P2S_PLA.3mf` 后，检查设备和耗材是否与下面一致：

- P2S，0.4 mm 标准流量喷嘴。
- Generic PLA，喷嘴 220°C，纹理 PEI 板 55°C。
- 0.20 mm 层高，3 层墙，15% 填充。
- 普通自动支撑，阈值 30°，允许模型上生成支撑，8 mm 外侧裙边。
- 面板竖立，热床内旋转 45°，模型保持 100% 比例。

切片返回 Success，无警告。模型尺寸为 233.90 × 233.90 × 154 mm。预计总时间 8 小时 10 分钟，PLA 238.83 g，包含支撑。时间和耗材是软件估算。

`toolpath_top.png` 是实际挤出路径的俯视投影，灰色为模型，蓝色为支撑，黄色为裙边。`toolpath_check.json` 记录挤出线段端点范围；它不单独构成圆弧范围的完整检查。打印范围以切片器完整检查为准。

目前只完成切片验证，尚未验证实机打印稳定性、支撑拆除痕迹和安装间隙。先试印平板固定架，确认实物安装。若实际喷嘴、PLA 类型或热床与此配置不同，需要重新切片。
